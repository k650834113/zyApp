# 0.21.0

- 商户管理员可在当前租户下创建第二家门店，并生成绑定租户、门店和允许动作的 30 分钟首设备启用码。
- 普通门店加入码只允许加入既有门店，不能创建租户或门店；启用码重复请求可幂等恢复且云端只保存 HMAC 哈希。

- 门店授权变更通过版本事件使旧离线凭据失效；禁止移除一家门店的最后一名有效店长。

# 0.20.0

- 每个门店配置使用独立 SQLite、云端设备令牌、同步队列与游标、备份、日志、素材和记住登录数据。
- 旧版单门店数据目录自动登记为兼容配置，不搬移、不覆盖现有数据库；新加入门店写入独立配置根。
- 切换前会关闭当前同步与数据库连接；登录中、同步中、结果待确认或镜像待修复时拒绝切换。
