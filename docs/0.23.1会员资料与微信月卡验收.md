## 体验版人工验收

- 首页会员名称、会员等级及小尺寸“编辑”按钮均完整可见。
- 首页月卡为独立橙金色大卡片，价格、有效期、开通或续费按钮清晰可见。
- 新会员微信开通月卡后立即生效，储值余额不增加。
- 已有生效月卡微信续费后，以原到期时间为基准顺延。
- 暂停月卡不能自助续费，并显示联系门店恢复的提示。
- PC 执行线下现金充值后，小程序明细显示“线下充值”；冲正后显示“已冲正”。
- PC 充值产生或撤销高级会员资格后，小程序会员等级与 PC 一致。
- PC 刷新云端数据后能看到小程序购买的月卡，支付方式显示“微信支付”。
- 快捷充值和自定义充值仍使用真实微信支付；体验版与生产版功能一致，仅 API 和数据库不同。
- 首页、明细和我的资料页面不再重复显示内容区页面标题。
