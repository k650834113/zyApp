# ZyApp 0.23.0 会员小程序与交易记录验收

验收日期：2026-07-25  
代码分支：`codex/member-recharge-pc-transactions`

## 本版范围

- 小程序仅保留游客入口、会员登录、余额/月卡/历史、会员资料和真实微信充值。
- 正式测试版使用真实微信登录与真实微信支付，但业务数据写入隔离测试库。
- 体验版与正式版都提供 100、300、500、1000 元快捷充值和最低 0.01 元的自定义充值。
- PC 端新增消费单与储值单查询；收银主页可手动刷新现场充值结果。
- 店员、店长移动端能力不在本版范围内。

## 需要用户在真机完成

- [ ] 使用测试库已有手机号首次绑定，确认直接进入首页，保留数据库会员名；无历史头像时显示默认头像。
- [ ] 使用测试库不存在的新手机号首次绑定，确认进入资料完善页，只填写 2–12 字会员名、不选头像也能完成注册。
- [ ] 新会员选择头像后保存，确认不再出现 `Cannot POST /v1/member/profile` 或 `Cannot POST /v1/member/profile-with-avatar`。
- [ ] 已有会员从“我的资料”上传头像，退出后重新进入，确认头像仍能显示。
- [ ] 模拟头像上传失败，确认首次注册可明确选择默认头像继续，而编辑资料时不会误报保存成功。
- [ ] 修改会员名和头像，确认 PC/数据库读取到更新结果。
- [ ] 发起 0.01 元充值后取消，确认页面不再显示待支付充值单。
- [ ] 完成一笔 0.01 元真实支付，确认余额只增加一次。
- [ ] 依次选择 100、300、500、1000 元快捷金额，确认每档均进入同一微信支付流程并可取消。
- [ ] 输入三位小数、零和超上限金额，确认客户端拒绝且不会创建充值订单。
- [ ] 使用储值余额消费一次，确认小程序最近明细只显示一条消费记录。
- [ ] 在 PC“交易明细”分别查看对应消费单和微信储值单。
- [ ] 再完成一笔手机充值，点击收银页“刷新”，确认当前会员余额更新且购物车、备注和支付方式未丢失。
- [ ] 保持当前线上小程序可用，同时上传体验版；确认体验版访问测试数据，线上版仍访问生产数据。
