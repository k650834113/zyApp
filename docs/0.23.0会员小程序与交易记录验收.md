## 本版范围

- 小程序仅保留游客入口、会员登录、余额/月卡/历史、会员资料和真实微信充值。
- 正式测试版使用真实微信登录与真实微信支付，但业务数据写入隔离测试库。
- PC 端新增消费单与储值单查询；收银主页可手动刷新现场充值结果。
- 店员、店长移动端能力不在本版范围内。

## 需要用户在真机完成

- [ ] 新手机号授权后完成注册，并选择微信昵称或填写自定义会员名。
- [ ] 上传头像，退出后重新进入，确认头像仍能显示。
- [ ] 修改会员名和头像，确认 PC/数据库读取到更新结果。
- [ ] 发起 0.01 元充值后取消，确认页面不再显示待支付充值单。
- [ ] 完成一笔 0.01 元真实支付，确认余额只增加一次。
- [ ] 使用储值余额消费一次，确认小程序最近明细只显示一条消费记录。
- [ ] 在 PC“交易明细”分别查看对应消费单和微信储值单。
- [ ] 再完成一笔手机充值，点击收银页“刷新”，确认当前会员余额更新且购物车、备注和支付方式未丢失。

真机验收后可补充：手机型号、微信版本、小程序构建时间、商户订单号末四位和已遮挡手机号的截图。请勿提交完整交易号、手机号、密钥或证书。
