- 发布包由显式提交通过 `git archive` 生成，tracked worktree 必须干净。
- 候选镜像在独立目录构建，正式启动使用 `--no-build`，运行镜像只来自指定提交。
- `.dockerignore` 排除 `infra/deploy/*.env*`，环境文件和备份不会进入镜像。
- 生产、测试和迁移数据库身份在备份与支付变更前精确核对。
- 正式发布不调用 `migrate-test`，不重建 `api-test`，不迁移或导入测试库。
- 测试 API 容器 ID、数据库身份、迁移和测试支付金额配置必须发布前后完全一致。
- SSH 退避重试只用于只读预检、幂等上传和临时目录清理；真正的生产变更命令只执行一次。
