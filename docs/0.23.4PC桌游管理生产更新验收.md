## 发布范围

- 将 PC 桌游管理从内容管理中拆分，并采用桌游单行列表、筛选和宽屏双栏编辑器。
- 修复仅包含别名的 BGG 搜索结果无法导入的问题。
- 加入封面预览、缓存失败恢复、本地上传和默认封面操作界面。
- 只更新生产 Windows 自动更新通道；测试更新通道、API、Worker、数据库及环境配置均保持不变。
- BGG 封面抓取和服务器缓存需要后续单独部署生产 API 并启用图片能力，本次 PC 更新不宣称该链路可用。

## 发布顺序

1. 发布契约和桌面类型检查通过。
2. 从当前 Git `HEAD` 构建 0.23.4 安装包、blockmap、`latest.yml` 和 `release-manifest.json`。
3. 使用发布脚本的生产通道 Dry Run 核对 SSH 身份、远端目录、公开地址和文件清单。
4. 仅上传到生产 Windows 更新目录，并验证公开 `latest.yml` 与 Range 下载。
5. 确认测试更新通道版本未变化。

## 停止条件

- 版本、发布说明、文件大小或哈希不一致。
- 生产更新目录或公开地址不符合生产通道。
- SSH 主机密钥未固定，或者生产发布过程中测试通道发生变化。
- 发布动作包含后端服务、数据库、环境文件或源码部署。

## 2026-08-12 发布后 API 热修与图片能力启用

- 用户在已升级到 0.23.4 的生产 PC 上复现 BGG 搜索仍返回畸形元数据错误；核验确认原 0.23.4 发布契约只更新桌面端，服务器仍运行修复前的解析器。
- 先后更新测试与生产 API，真实验证中文“卡坦岛”、英文 `Catan` 以及仅含 alternate name 的 BGG 134277 均可正常解析；数据库、Worker 和桌面更新通道保持不变。
- 负责人随后明确确认商业授权允许获取、缓存并跨端展示 BGG 封面。测试环境先启用图片能力并完成 BGG 13 真实封面缓存与公开回读，生产环境通过相同验证后启用 `BGG_PUBLIC_IMAGES_ENABLED=true`。
- 测试和生产分别使用独立持久卷；两端回读文件均为同一 380147 字节 PNG，内容 SHA-256 为 `784c3d4b86917754a42d9664c004e279d9f39389c56065ce7dc6ca64bf89878a`，响应包含一年不可变公开缓存头。
