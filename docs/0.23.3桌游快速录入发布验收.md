## 发布范围

- PC 桌游快速录入、表单校验与图片导入。
- BGG 元数据搜索、详情导入和中文名称/中文简介人工确认。
- SQLite Schema 30 的桌游复杂度与元数据来源字段。
- PostgreSQL Migration 20 的 BGG 来源字段与租户内 BGG ID 唯一约束。
- API 元数据可用性、搜索和详情接口；BGG 授权未启用时返回关闭状态，不影响手工录入。
- BGG Commercial Application 已审核通过，服务端 Token 真实搜索返回 HTTP 200；公开图片保持关闭。
- 测试与生产 Windows 自动更新通道同时升级到 0.23.3。

## 发布顺序

1. 所有自动测试、类型检查、构建和发布契约通过。
2. 从 Git `HEAD` 生成部署源码包，工作区未提交或未跟踪文件不得进入压缩包。
3. 构建一次 0.23.3 安装包、blockmap、`latest.yml` 和 `release-manifest.json`，独立复核 SHA-256。
4. 先备份并部署测试数据库/API/Worker，确认迁移 20、健康检查和测试更新通道均正常。
5. 使用真实设备凭据验证测试 API 的 BGG 可用性、搜索与详情导入后，备份并部署生产数据库/API/Worker，确认迁移 20、健康检查和生产更新通道均正常。
6. 最后确认测试、生产更新通道均为 0.23.3，安装包与 blockmap 可以下载。

## 停止条件

- 任一自动测试、类型检查或构建失败。
- 安装包、blockmap 或 `latest.yml` 的大小、SHA-256 与发布清单不一致。
- 测试环境部署失败或未达到迁移 20 时，禁止开始生产部署。
- 生产备份失败时，禁止迁移生产数据库。
- 任一健康检查失败、更新版本不为 0.23.3，或测试通道在生产部署后发生异常变化。
