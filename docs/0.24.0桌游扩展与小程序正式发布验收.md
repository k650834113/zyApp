## 发布范围

- PC 桌游录入支持选择基础游戏或扩展，并为扩展指定唯一基础游戏。
- SQLite Schema 31、PostgreSQL Migration 21、云同步、镜像回写与公开接口传递 `baseGameId`。
- 小程序桌游库以基础游戏为父项，点击父项展开或收起所属扩展。
- 公开桌游查询上限提升到 1000，覆盖当前基础游戏与扩展完整库存。
- 从上一轮集石库存清单补录 143 个扩展；缺失的父游戏先补录，所有扩展必须拥有有效且非扩展的父游戏。
- PC 0.24.0 更新包投放生产通道；小程序构建正式生产配置并上传微信后台，供管理员提交审核发布。

## 发布顺序

1. 自动测试、类型检查、构建和发布契约通过。
2. 从 Git `HEAD` 构建 0.24.0 安装包并复核安装包、blockmap、`latest.yml` 与发布清单哈希。
3. 备份生产 PostgreSQL，部署 API/Worker 并迁移至 21；验证生产健康、测试通道未变化。
4. 备份生产 PC 镜像库，升级到 SQLite 31，先补缺失父游戏，再录入 143 个扩展并通过 outbox 同步。
5. 核对本地与云端扩展数量、父级外键、无扩展嵌套、无孤儿记录，并验证公开接口返回完整数据。
6. 构建小程序正式包，验证 API 地址与正式门店 ID 后上传微信后台。

## 停止条件

- 任一自动检查、构建、哈希或健康检查失败。
- 生产备份未成功，或迁移版本不是 21。
- 扩展数量不是 143、存在孤儿父级、父级本身是扩展，或发现重复 BGG 编号。
- 小程序正式包指向测试 API、Mock 模式或错误门店。
- 生产部署意外改变测试 PC 更新通道或测试数据库。
